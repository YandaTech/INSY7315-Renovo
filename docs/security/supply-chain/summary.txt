Dependency patch and pin (RN-0019), 2026-11-02
==============================================

Tools: npm 11.20.0 (npm audit), pip-audit 2.10.1 run with `uvx pip-audit`.
Raw output: before/ and after/ in this folder.

How "before" was measured for Python: the old unpinned specs (>=) were
installed into fresh Python 3.12 venvs and audited with
`pip-audit --path <site-packages>`. "After" audits the committed lock
files: `pip-audit --disable-pip --no-deps -r requirements.txt`.

CI enforcement (RN-0029)
------------------------
The `security-scan` job in .github/workflows/ci-cd.yml runs on every push
and fails the build on a finding. It runs `npm audit --audit-level=high`
in frontend/ and voice-bridge/ (dev dependencies included), and
`pip-audit --disable-pip --no-deps -r requirements.txt` (pip-audit 2.10.1)
on the backend, mcp-pricing-server and ai-agent lock files. pip-audit has
no severity filter, so any known Python vulnerability fails the build.
